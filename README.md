# Web Development Practicals

Repository containing web development practical lab assignments and projects.

## Project Structure

- **[Practical 1: Electronics Store](./Practical_1_Electronics_Store)**
  - Basic Electronics Store built with semantic HTML and external/internal CSS styling.
- **[Practical 2: Student Registration](./Practical_2_Student_Registration)**
  - Student Registration form with client-side JavaScript validation and interactive styling.
- **[Practical 3: React Student Management](./Practical_3_React_Student_Management)**
  - Student Management single-page application built with React and Vite.
- **[Practical 4: Next.js Blog](./Practical_4_NextJS_Blog)**
  - Multi-page dynamic blog application built using Next.js.
- **[Practical 5: React Exam Result](./Practical_5_React_Exam_Result)**
  - Exam Result portal built with React and Vite.

## Getting Started

For the React / Next.js practicals (Practicals 3, 4, 5):

1. Navigate to the practical folder:
   ```bash
   cd Practical_3_React_Student_Management
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
